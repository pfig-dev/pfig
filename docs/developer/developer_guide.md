# Developer Guide

This guide is for developers who want to contribute to pfig or understand its internals. For using pfig, see the [Getting Started](../guides/getting-started.md) guide. For syntax details, see the [Syntax Reference](../reference/syntax_reference.md).

## Overview

The Developer Guide is organized into focused sections:

- **[Development Setup](developer_setup.md)** - Setting up your development environment
- **[Architecture](architecture.md)** - Understanding pfig's internal architecture and components
- **[Development Workflow](development_workflow.md)** - How to work on pfig, add features, and write tests
- **[Contributing](contributing.md)** - Contribution guidelines and PR process
- **[Developer Debugging](developer_debugging.md)** - Debugging tools for working on pfig

## Quick Start

1. **Set up your environment**: See [Development Setup](developer_setup.md)
2. **Understand the architecture**: Read [Architecture](architecture.md)
3. **Learn the workflow**: Check out [Development Workflow](development_workflow.md)
4. **Start contributing**: Follow the [Contributing](contributing.md) guidelines
